# Contributing

Thank you for wanting to contribute. The short version:

1. Open an issue first for anything non-trivial (>30 lines, new dependency, public API change).
2. Sign the [CLA](./CLA.md) by checking the box in your first PR.
3. Code style: TypeScript strict mode, files ≤ 500 lines, no `any`, no `as` casts without comment.
4. Tests required for coordinate transforms, EKF code, and the rendering shader.
5. PRs are squash-merged with a Conventional Commits title (`feat:`, `fix:`, `docs:`, etc.).

## Dev setup

```bash
git clone https://github.com/<owner>/ar-night-sky.git
cd ar-night-sky
npm install
npm run dev      # local dev server with hot reload
npm run test     # vitest
npm run build    # production build
npm run preview  # serve the production build locally
```

## Branch + PR workflow

- `main` is always shippable
- Feature branches: `feat/<short-name>`
- Bugfixes: `fix/<short-name>`
- PRs target `main`; CI must pass before merge

## What we want help with

- WebGL2 shader optimization (PSF rendering, HDR tone mapping)
- IMU + plate-solve EKF tuning (better gyro-bias estimation)
- HEALPix tile pipeline for Pan-STARRS deep-sky data
- Per-vendor AR-glasses adapters (Xreal NebulaOS, Viture, Rokid SDKs)
- Documentation, tests, accessibility

## What we don't want

- Surprise framework rewrites
- New dependencies that haven't been discussed in an issue first
- Closed-source binary blobs
- Code generated by AI without human understanding / verification (you must be able to explain every line in your PR)

## The CLA — why it exists

This project is licensed under AGPL-3.0. For the project to also offer **commercial licenses** to companies that can't accept AGPL obligations, the maintainer needs the right to relicense contributions. The CLA grants that right while keeping you the copyright holder. It's the same model used by Apache Foundation, MongoDB, Qt, and GitLab.

You sign the CLA once. After that, all your future PRs to this repo are covered.

## License of contributions

By submitting a PR, you confirm:
- You wrote the code yourself, or have the right to submit it
- You agree to license your contribution under AGPL-3.0
- You grant the maintainer the right to also offer your contribution under commercial-license terms (this is the CLA)

## Code of conduct

Be kind. Cite sources for non-obvious algorithms (astrometry, photometry, color science). Respect the prior art — this project sits on top of decades of open-source astronomy work.
